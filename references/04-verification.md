# Stage ④ 双重校验：真实性 + 易懂性（skill 规格 · 04）

> Stage ④：逐字稿定稿前的质量门。可由两个独立子代理并行执行（互不污染视角）。

## A. 真实性校验（Veracity）

逐句扫描 narration.md，产出核查表：

| 句 id | 断言摘要 | 事实源锚点 | 判定 |
|---|---|---|---|
| p2-14 | 一致≠正确，自信地错会放大 | §5.2 风险第 3 条 | ✅ |

- **判定级别**：✅ VERIFIED（原文可回溯）/ ⚠️ ANALOGY（比喻性引申，比喻与事实边界清晰）/ ❌ RISKY（无锚点或与原文有出入）/ ✏️ REWRITE（表述需修正）。
- **定稿门槛：RISKY 与未处理 REWRITE 必须为零。**
- 比喻句必须显式归类 ANALOGY 且核对本体不与论文矛盾（例如「在梦里练车」是比喻，但「梦有偏差、上路前需验证」这一约束句必须是 VERIFIED）。
- 数字、系统名、人名、年份逐一核对。

## B. 易懂性评审（Accessibility）

以「不预设 ML 背景、智商在线但外行」的观众视角通读：

- 每个新术语出现处，前一句或后一句内是否有比喻/白话解释？
- 代词指代是否清晰（「它」「这条路」——离先行词太远则重写）？
- 是否存在连续 3 句以上无画面感抽象论述（标记加比喻或例子）？
- 金句卡候选（英文原文金句 ≤3 处/幕，过密则贬值）；
- 听觉友好：避免连读歧义、避免中英夹杂同一句。

**外行瞬时理解三判据**（RSI-015 追加。上面五条全是句级局部判据——jev 集实证：
五条全检通过、普通观众仍「一脸懵」，三个名词系统全部先用后讲，且每个解释本身
又用了未解释概念。判据从「解释存在」升到「解释到达时观众还在线」）：

- **解释可懂性**：术语首现的解释本身是否用了外行懂的话？递归一层检查——比喻
  不能建立在另一个未解释概念上（「集中度就像校准度」对不懂校准度的人是零信息）；
- **先释后用**：术语首次**承担载荷**（参与因果 / 触发动作 / 被比较）时，解释须已在
  前一句出现过——不能靠后一句补救：载荷已压在未解释的词上，观众那时已经掉线
  （第一条判据的「前一句或后一句」对本判据覆盖的载荷场景收紧为「前一句」）；
- **密度预算**：每 beat 新术语 ≤2 个、每幕 ≤8 个；超出须拆 beat 或用白话替代
  消除术语。机器面（WARN 级）：评审员圈定本集术语系统后跑
  `uv run --no-project $T/scripts/check_script.py --project $P --term-density --terms 集中度,门槛,计费单位`
  （中文术语声明计入、拉丁字母词自动计入；beat 边界读 narration.json 的
  beatStart，幕内空行 = 一个 beat）。

**被动收看双门**（RSI-032 追加。三判据查「解释到达时观众还在线」，双门查「被动
线性收看」——视频观众无法停顿回翻，句级判据之外须再过两道过程级门）：

- **过程具象化在场（No Rule Without Trace）**：观众被动看视频无法像读文档那样停顿推演——每个核心机制幕（`P1..Pk`）必须至少含 **1 个具体输入走查 beat（Worked Example）或正反破坏性对比 beat**（带具体输入值走完「进入 → 状态变换 → 结果」或「拔掉该设计在哪一步崩」）；整幕仅陈述抽象规则而无具体走查过程，直接判 `REWRITE`；
- **线性收看零回溯负担（Zero Backward-Lookup）**：视频是单向线性流，严禁跨幕/跨 beat 出现「上面第一种做法」「前面那个参数」等需观众凭记忆回翻的悬空暗指；重提旧概念须用**「具名短词 + 画面母题同步复现」**就地唤醒。

## C. 译文保真校验（双语集的第三门）

双语集对 `narration.en.md` 逐句做「主稿断言的等价翻译」核查（机器门只管对齐与失鲜，语义保真在此门）：

- **不引入**：en 句不得包含主稿对应句没有的断言、数字或因果（新增信息 ⇒ RISKY——事实源是 Stage ① 事实源（B/C 型下同），不是译者的补充知识）；
- **不删限**：主稿的限定词（「约」「可能」「至多」→ about / may / up to）丢失即弱化断言 ⇒ REWRITE；
- **喻体一致**：同一比喻在全片保持同一英文意象，不中途换喻；术语首现的解释句随主稿同步翻译；
- 判定沿用 A 的四级制（VERIFIED / ANALOGY / RISKY / REWRITE），定稿门槛同为 RISKY 与未处理 REWRITE 清零。

## 输出

两份报告合并为逐字稿头部版本号升级依据（如 v1 → v2，已过双重校验）。所有 REWRITE 修正直接落回 narration.md，再复跑 A 直到清零。清零后交 [⑤ 成文优化](./05-prose-refinement.md)；⑤ 改过的句子会带着改动表回到本规格做**改动句复核**（A 节四级判定 + B 节前三条与 RSI-032 被动收看双门，只核改动句；研究笔记的改动句以信源原文为锚，见 05 第九节第 4 步）。

**分工**：本阶段判「对不对、懂不懂」（B 节的术语降落、指代距离、抽象连段仍在此查）；篇章结构、段间衔接、句子节奏与去机器味归 ⑤，不在此重复。
